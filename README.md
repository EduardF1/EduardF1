## Hi, I am Eduard

Full-stack and platform engineer based in Aarhus, Denmark. I build and run software end to end:
.NET, TypeScript/React, cloud infrastructure, and agentic AI tooling (Claude Code, MCP, local LLM
fleets on a home RTX 5090).

Most of my current work lives in private repositories:

- **OmniControl** - my main project: a modular control surface for an AI agent estate, with a
  workspace of sovereign modules, a reviewed bus, and mechanical quality gates.
- **A home AI estate** - a multi-agent infrastructure that runs real workloads: semantic memory,
  cross-audit review gates, benchmarks with a planted-defect suite, and a local model fleet.
- **The 2021 learning archive** - 56 self-study projects (React, web dev, language hands-on) kept
  as one organized repository, deliberately private.

Public and open for anyone:

- **OSS contributions** - 45 merged pull requests across 32 upstream projects, among them angular,
  eslint, jest, vite, freeCodeCamp, dotnet/aspnetcore, dotnet/sdk, fastify, hono, react-hook-form
  and kobalte. The forks here are contribution evidence.
- **University coursework** - two public repositories from the VIA years, `viauc-dai1-s22`
  and `Android_Exam_Practice`. The rest of the `via-bachelor` bucket is private.
